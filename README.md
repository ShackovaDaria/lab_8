# Домашнее задание к работе 8

## Условие задачи
Вычислите с использованием цикла for значение ряда, для заданных пользователем значений a и n.
Формула: a * (a - n) * (a - 2n) * ... * (a - n^2)

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Настраиваем кодировку (локаль UTF-8), чтобы русские буквы в консоли отображались правильно.
3. Запрашиваем у пользователя два числа: вещественное число `a` и целое число `n`.
4. Делаем проверку: если `n < 0`, выводим сообщение об ошибке. В противном случае вызываем функцию `proizv`, передаем ей `a` и `n`, а результат сохраняем в переменную `res`. Затем выводим `res` на экран с точностью до 6 знаков после запятой.
5. **Конец**.

**Часть 2: Функция вычисления (proizv)**
1. **Начало функции**: получаем числа `a` и `n`.
2. Создаем переменную `res` и присваиваем ей начальное значение `1.0` (так как мы ищем произведение).
3. Запускаем цикл `for`, где переменная `k` меняется от `0` до `n` включительно (на последнем шаге `k = n`, поэтому множитель будет `a - n * n`, что и соответствует `a - n^2`).
4. Внутри цикла на каждом шаге умножаем текущее значение `res` на очередной множитель: `res = res * (a - k * n)`.
5. После завершения цикла возвращаем итоговое значение `res` в главную функцию.
6. **Конец**.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

double proizv(double a, int n);

int main()
{
    double a, res;
    int n;

    setlocale(LC_ALL, ".UTF8");

    printf("Введите число a: ");
    scanf("%lf", &a);
    printf("Введите целое число n (n >= 0): ");
    scanf("%d", &n);

    if (n < 0)
    {
        printf("Ошибка: n должно быть неотрицательным\n");
    }
    else
    {
        res = proizv(a, n);
        printf("Значение выражения: %.6lf\n", res);
    }
    return 0;
}

double proizv(double a, int n)
{
    int k;
    double res = 1.0;

    // Цикл от 0 до n включительно (так как последний множитель a - n*n)
    for (k = 0; k <= n; k++)
    {
        res = res * (a - k * n);
    }
    return res;
}
```
